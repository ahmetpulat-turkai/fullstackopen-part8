# Full Stack Open - Part 8 (GraphQL)

Exercises 8.1-8.24 and 8.28 (n+1) of the Full Stack Open GraphQL part: `library-backend` (Apollo Server + MongoDB/Mongoose, JWT login), `library-frontend` (React + Apollo Client), and the provided tests in `tests-chapter4` and `tests-chapter5`. Optional subscription exercises 8.25-8.27 are not implemented.

Run the backend with `MONGODB_URI`, `JWT_SECRET` (and optional `PORT`) set in `library-backend/.env`.
